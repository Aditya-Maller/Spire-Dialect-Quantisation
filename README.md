# Spire Labs Audio Quantization Telemetry App

This project transforms academic research on Kannada dialect identification into a full-stack, containerized web application. It serves as an interactive observability tool demonstrating the effects of extreme audio quantization on deep learning models.

## Project Structure
* `Backend/`: FastAPI application and ONNX models for serving inference.
* `Frontend/`: React application for the user interface and interactive telemetry visualization.
